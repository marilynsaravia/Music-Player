## Description
This application is a **Digital Music Player** built using HTML5, CSS3, and Vanilla JavaScript. It provides a smooth, fast, and intuitive interface for playing audio tracks directly from a local environment.

It’s designed for users who want a clean, no-nonsense audio experience with a focus on simple navigation and modern aesthetics.

### Current Features:
- **Core Playback:** Full control with Play, Pause, Next, and Previous track functionality.
- **Dynamic UI:** Real-time updates of song titles, artist names, and album covers using DOM manipulation.
- **Seamless Flow:** Auto-play feature that automatically starts the next song when the current one ends.
- **Local Storage Optimization:** Audio assets are hosted directly within the project structure for instant loading and offline capability.
- **Responsive Design:** A sleek and adaptive interface that scales perfectly across different devices.
